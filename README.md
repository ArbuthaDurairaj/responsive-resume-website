# Responsive Resume Website

This project was developed as part of a Web Programming course assignment.

The website demonstrates foundational front-end web development concepts using HTML and CSS, including:

- Multi-page website navigation
- Resume and profile presentation
- Structured layouts using semantic HTML
- CSS styling and responsive design basics
- Contact and project pages

## Technologies Used

- HTML5
- CSS3

## Purpose

The purpose of this project was to practice frontend web development concepts and build a personal resume-style website as part of academic coursework.
